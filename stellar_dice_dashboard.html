STELLAR CALL

Campaign Dice Roller

How to Use This Dashboard
1. Select Campaign Phase
Choose Early, Mid, or Late Campaign to adjust Stellar Call and Random Encounters table interpretations.
2. Roll Stellar Die (d8)
Each crew member rolls when entering hyperspace. Track results to find matching intensity brackets.
3. Check for Phenomena
If 2+ crew match intensity (3-5, 6-7, or 8), roll Hyperspace Phenomena. Use the bracket that triggered.
4. Random Encounters
Roll d20 when crew has downtime between destinations. Intensity increases with campaign phase.
5. Ship Complications
Roll d10 for organic system failures during downtime, post-combat, or post-jump.
The Stellar Die
For skill checks: 1-2 = Complication, 3-4 = Clean Result, 5-6 = Opportunity. Affects story, not math.

Quick Reference
When to Use the Stellar Die
Always: Character goals, critical story beats, confrontations with named NPCs, moral choices

Consider: Creative solutions, character motivations, key combat moments (~33%), investigations

Never: Routine operations, shopping, low-stakes interactions, obvious answers
Opportunity (5-6)
Grant advantage, gain Power, critical hit, discover info, beneficial circumstance, reduce cost/time
Complication (1-2)
Enemy advantage, lose Power, detrimental circumstance, attract attention, trigger alert, complication
